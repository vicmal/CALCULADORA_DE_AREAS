# LEVANTAMIENTO PLANIMÉTRICO
Calcula área mediante coordenadas UTM, capturadas en sitio o tomadas con un GPS independiente o calculadas a partir de un levantamiento topográfico convencional. Su objetivo es solo calcular el área y mostrar el polígono en una imagen de satélite. Te entrega un archivo en formato .dxf para que lo descargues y edites en AutoCad
